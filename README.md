
# Una pregunta para ti

Una página web romántica creada como una propuesta de noviazgo para una pareja de chicas que mantiene una relación a distancia.

## Descripción

Este proyecto es una carta de amor digital con un diseño elegante y minimalista. Utiliza tonos amarillo mantequilla, dorado, crema y blanco para crear una experiencia visual delicada y romántica.

## Características

- Diseño elegante y adaptable a dispositivos móviles.
- Paleta de colores amarillos y dorados.
- Carta de amor personalizada.
- Sección dedicada a una relación a distancia.
- Promesas para construir una relación saludable.
- Propuesta de noviazgo interactiva.
- Animaciones y transiciones suaves.
- HTML, CSS y JavaScript integrados en un solo archivo.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Cómo utilizar el proyecto

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Personaliza los textos para contar tu propia historia.

## Publicar con GitHub Pages

1. Sube los archivos a un repositorio de GitHub.
2. Entra en Settings.
3. Selecciona Pages.
4. En Build and deployment, elige Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios y espera a que GitHub publique la página.
